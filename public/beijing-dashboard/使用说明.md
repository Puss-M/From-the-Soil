# 北京四合院数据大屏 - 使用说明

## 📋 项目概述

这是一个1:1复刻的北京四合院文化数据可视化大屏，采用**1920×1080固定布局**，实现了中国风水墨画背景的数据展示效果。

## 🎨 设计特点

### 1. 布局系统
- **固定尺寸**: 1920×1080 像素
- **绝对定位**: 所有模块使用精确坐标
- **等比缩放**: 自动适配不同屏幕尺寸
- **无响应式重排**: 保持设计稿原始比例

### 2. 视觉风格
- **背景**: 中国水墨画风格
- **配色**: 土黄、青蓝、赤红色系
- **字体**: 楷体标题 + 微软雅黑正文
- **透明度**: 玻璃拟态面板效果

### 核心技术
- **ECharts 5.x**: 图表渲染引擎
- **ECharts WordCloud**: 词云插件
- **绝对定位布局**: CSS absolute positioning
- **等比缩放**: JavaScript transform scale

### 关键代码

#### 1. 等比缩放函数
```javascript
function fitScreen() {
  const baseWidth = 1920;
  const baseHeight = 1080;
  const scaleX = window.innerWidth / baseWidth;
  const scaleY = window.innerHeight / baseHeight;
  const scale = Math.min(scaleX, scaleY);
  const screen = document.getElementById('screen');
  screen.style.transform = `scale(${scale})`;
  
  const offsetX = (window.innerWidth - baseWidth * scale) / 2;
  const offsetY = (window.innerHeight - baseHeight * scale) / 2;
  screen.style.left = `${offsetX}px`;
  screen.style.top = `${offsetY}px`;
}
```

## 🚀 快速开始

### 1. 直接打开
双击 `index.html` 文件即可在浏览器中查看。

### 2. 本地服务器（推荐）
```bash
# 使用Python
cd 北京四合院
python -m http.server 8000

# 使用Node.js
npx http-server -p 8000

# 访问 http://localhost:8000
```

### 3. 全屏显示
按 `F11` 进入浏览器全屏模式，获得最佳展示效果。

## ⚠️ 注意事项

### 1. 浏览器兼容性
- ✅ Chrome 90+
- ✅ Edge 90+
- ✅ Firefox 88+
- ⚠️ Safari 14+ (部分效果可能不同)
- ❌ IE 11 (不支持)

### 2. 性能优化
- 图表数量较多，建议在性能较好的设备上运行
- 如遇卡顿，可减少词云词汇数量
- 关闭浏览器其他标签页

### 3. 常见问题

**Q: 背景图不显示？**
A: 检查 `风物志背景.jpeg` 文件是否存在于正确路径。

**Q: 地图不显示？**
A: 确保 `js/china.js` 文件已正确加载。

**Q: 词云不显示？**
A: 检查是否引入了 `echarts-wordcloud.min.js` 插件。

**Q: 布局错乱？**
A: 确保浏览器缩放比例为100%，清除缓存后刷新。
