# 🐛 调试指南 & 问题排查

## 快速诊断流程

### 步骤1: 打开开发者工具
```
Chrome/Edge: F12 或 Ctrl+Shift+I
Firefox: F12 或 Ctrl+Shift+K
Safari: Cmd+Option+I (需先在设置中启用)
```

### 步骤2: 检查控制台错误
按优先级排查：
1. **红色错误** (Error) - 必须立即修复
2. **黄色警告** (Warning) - 可能影响功能
3. **蓝色信息** (Info) - 仅供参考

## 🔍 常见问题排查

### 问题1: 页面完全空白

#### 可能原因
- [ ] HTML文件路径错误
- [ ] 浏览器不支持ES6语法
- [ ] JavaScript报错导致全局崩溃

#### 排查步骤
```javascript
// 1. 检查控制台是否有报错
F12 → Console → 查看红色错误

// 2. 检查文件是否加载成功
F12 → Network → 刷新页面 → 查看是否有404错误

// 3. 检查JavaScript语法
查找是否有 SyntaxError
```

#### 解决方案
```html
<!-- 确保文件路径正确 -->
<script src="js/js.js"></script>  ✅
<script src="./js.js"></script>   ❌ 路径错误

<!-- 确保jQuery在ECharts之前加载 -->
<script src="js/jquery.js"></script>
<script src="https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js"></script>
```

### 问题2: 背景图片不显示

#### 可能原因
- [ ] 图片路径错误
- [ ] 图片文件不存在
- [ ] CSS路径相对问题

#### 排查步骤
```css
/* 1. 检查CSS中的路径 */
/* comon0.css 第 30 行 */
background: url('../../风物志背景.jpeg');

/* 2. 确认图片是否存在 */
项目根目录/风物志背景.jpeg  ✅

/* 3. 检查Network面板 */
F12 → Network → Img → 查看图片是否404
```

#### 解决方案
```css
/* 方法1: 使用绝对路径 */
background: url('/风物志背景.jpeg');

/* 方法2: 使用相对路径（推荐） */
background: url('../../风物志背景.jpeg');

/* 方法3: 使用base64编码（小图片） */
background: url('data:image/jpeg;base64,...');
```

### 问题3: 地图不显示

#### 可能原因
- [ ] china.js 未加载
- [ ] 地图数据格式错误
- [ ] ECharts版本不兼容

#### 排查步骤
```javascript
// 1. 检查china.js是否加载
console.log(typeof echarts.getMap('china'));  
// 应输出 'object'，如果是 'undefined' 说明未注册

// 2. 检查控制台报错
"Cannot read property 'map' of undefined"  // 未加载地图数据
"Map not exists"  // 地图未注册

// 3. 检查Network
F12 → Network → JS → 查找 china.js
```

#### 解决方案
```html
<!-- 确保china.js在图表初始化之前加载 -->
<script src="js/china.js"></script>
<script src="js/js.js"></script>

<!-- 或使用ECharts官方地图 -->
<script src="https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json"></script>
```

```javascript
// 注册地图数据
echarts.registerMap('china', chinaJson);
```

### 问题4: 词云不显示

#### 可能原因
- [ ] echarts-wordcloud插件未加载
- [ ] 数据格式错误
- [ ] 容器高度为0

#### 排查步骤
```javascript
// 1. 检查插件是否加载
console.log(typeof echarts.init);  // 应输出 'function'

// 2. 检查数据格式
data: [
  { name: '东城区', value: 120 }  // ✅ 正确
]
data: [
  { text: '东城区', size: 120 }   // ❌ 错误格式
]

// 3. 检查容器尺寸
const el = document.getElementById('chart-wordcloud');
console.log(el.offsetWidth, el.offsetHeight);
// 如果都是0，说明容器没有尺寸
```

#### 解决方案
```html
<!-- 确保引入词云插件 -->
<script src="https://cdn.jsdelivr.net/npm/echarts-wordcloud@2/dist/echarts-wordcloud.min.js"></script>

<!-- 或使用本地文件 -->
<script src="js/echarts-wordcloud.min.js"></script>
```

```css
/* 确保容器有高度 */
.panel-wordcloud {
  height: 384px;  /* 必须有固定高度 */
}
```

### 问题5: 图表显示不完整

#### 可能原因
- [ ] 容器尺寸过小
- [ ] grid/legend配置不当
- [ ] 数据超出范围

#### 排查步骤
```javascript
// 1. 检查容器尺寸
const chart = document.getElementById('chart-line');
console.log('容器尺寸:', chart.clientWidth, 'x', chart.clientHeight);

// 2. 检查grid配置
grid: { 
  left: 45,   // 左边距
  right: 35,  // 右边距
  top: 35,    // 上边距
  bottom: 35  // 下边距
}

// 3. 检查坐标轴范围
yAxis: {
  min: 0,
  max: 200  // 确保数据在此范围内
}
```

#### 解决方案
```css
/* 增加容器高度 */
.panel-line {
  height: 220px;  /* 建议不低于 180px */
}
```

```javascript
// 调整内边距
grid: { 
  left: '10%',   // 使用百分比
  right: '10%',
  top: '15%',
  bottom: '15%',
  containLabel: true  // 包含标签
}
```

### 问题6: 布局错乱/重叠

#### 可能原因
- [ ] 浏览器缩放不是100%
- [ ] 窗口太小导致缩放异常
- [ ] CSS定位冲突

#### 排查步骤
```javascript
// 1. 检查浏览器缩放
console.log('缩放比例:', window.devicePixelRatio);
// 应该是1.0，如果不是请重置浏览器缩放

// 2. 检查窗口尺寸
console.log('窗口尺寸:', window.innerWidth, 'x', window.innerHeight);
// 建议最小 1366x768

// 3. 检查transform scale
const screen = document.getElementById('screen');
console.log('当前缩放:', getComputedStyle(screen).transform);
```

#### 解决方案
```
1. 重置浏览器缩放: Ctrl + 0
2. 全屏显示: F11
3. 清除缓存: Ctrl + Shift + Delete
4. 强制刷新: Ctrl + F5
```

### 问题7: 仪表盘显示异常

#### 可能原因
- [ ] 数据格式错误
- [ ] 半圆配置不当
- [ ] 容器过小

#### 排查步骤
```javascript
// 1. 检查数据值范围
const values = [92, 48, 23];
// 应该在 0-100 之间

// 2. 检查startAngle和endAngle
startAngle: 180,  // 起始角度
endAngle: 0       // 结束角度
// 半圆仪表盘配置

// 3. 检查容器尺寸
.gauge-item {
  height: 140px;  // 必须足够高
}
```

#### 解决方案
```javascript
// 完整配置示例
{
  type: 'gauge',
  radius: '88%',
  center: ['50%', '55%'],
  startAngle: 180,
  endAngle: 0,
  min: 0,
  max: 100,
  data: [{ value: 92, name: '完整度' }]
}
```

### 问题8: 桑基图连接线不显示

#### 可能原因
- [ ] 节点名称不匹配
- [ ] 流量值为0
- [ ] 节点位置重叠

#### 排查步骤
```javascript
// 1. 检查节点名称
data: [
  { name: '大门' },
  { name: '影壁' }
]
links: [
  { source: '大门', target: '影壁', value: 10 }
  // source和target必须与data中的name完全一致
]

// 2. 检查流量值
{ source: '大门', target: '影壁', value: 10 }  // ✅
{ source: '大门', target: '影壁', value: 0 }   // ❌ 不会显示

// 3. 检查控制台警告
"sankey node not exists: 大门"  // 节点名称拼写错误
```

#### 解决方案
```javascript
// 确保名称完全匹配
const nodes = ['大门', '影壁', '垂花门'];
data: nodes.map(name => ({ name })),
links: [
  { source: nodes[0], target: nodes[1], value: 10 }
]
```
