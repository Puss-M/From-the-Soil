## 🎯 核心突破

### 1. 居中问题的本质
**不是缩放逻辑，而是坐标系统**

公式：
```
正确left = (舞台宽 - 内容总宽) / 2
         = (1880 - 1770) / 2
         = 55px

而不是20px
```

### 2. 文字颜色的本质
**不是随便选色，而是系统配色**

色系层级：
```
深棕金 #8a5a1f → 主标题、重要文字
中棕   #a2743c → 次要说明、轴名
浅棕   #9a6a2e → 图例、坐标刻度
```

### 3. 视觉校准的本质
**不是调单个参数，而是整体平移**

- 所有面板统一右移35px
- 所有白字统一改棕色
- 一次性解决系统问题
