# 北京四合院大屏 - 修改对照表

## 🔄 核心改动说明

### 1. 布局系统改造 ✅

#### 改动前
```css
/* 使用了flex/grid自动排版 */
.main-stage {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  height: 100%;
}
```

#### 改动后
```css
/* 使用绝对定位，固定坐标 */
.main-stage {
  position: absolute;
  left: 20px;
  top: 20px;
  width: 1880px;
  height: 1040px;
}
.panel {
  position: absolute;
  /* 每个面板有精确的 left/top/width/height */
}
```

**原因**: 大屏不需要响应式重排，固定坐标更稳定，符合1:1复刻要求。

### 6. 图表配置优化 ✅

#### 温雨双折图
**新增**: 渐变色柱状图、面积填充折线图、双Y轴标签

```javascript
// 旧版
itemStyle: { color: '#56c7d2' }

// 新版
itemStyle: { 
  color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
    { offset: 0, color: '#56c7d2' },
    { offset: 1, color: '#34c0d5' }
  ])
}
```

#### 分类图
**改动**: 从玫瑰饼图改为气泡散点图

```javascript
// 旧版

// 新版
type: 'scatter',
symbolSize: function(data) { return data[2]; }
```

**原因**: 目标大屏使用的是气泡图，展示效果更直观。

#### 雷达图

## 🎯 核心原则

### ✅ 坚持的原则
1. **固定布局优先** - 不使用百分比高度
2. **绝对定位** - 每个模块精确坐标
3. **1920×1080基准** - 固定设计稿尺寸
4. **等比缩放适配** - JavaScript动态scale
5. **图表独立容器** - 每个图表有固定宽高

### ❌ 避免的错误
1. ❌ 使用flex/grid自动排版
2. ❌ 百分比高度导致压缩
3. ❌ 图表容器过小
4. ❌ 顶部栏占用空间
5. ❌ 响应式重排布局
