### 问题1：标题视觉居中 ⭐⭐⭐⭐⭐

#### 核心突破
**不是几何居中问题，是视觉校准问题**

#### 修正方案 ✅
```css
.title-board {
  width: 460px;        /* 430→460 加宽 */
  letter-spacing: 2px; /* 4→2 关键！ */
}
```

#### 原理
- **letter-spacing过大** = 字间距太宽 = 视觉重心不稳
- **收紧到2px** = 字紧凑 = 自动看起来居中
- **加宽到460px** = 给紧凑后的字更多空间

#### 效果
- ✅ 视觉绝对居中（不是几何居中）
- ✅ 牌匾更稳重
- ✅ 压住中轴

**3. 关键技巧：数据顺序调整**
```javascript

  { name: '西城区', value: 140 },  // 放第一
  { name: '东城区', value: 150 },  // 放第二（避免压中心）
  ...
]
```

#### 原理
- ECharts优先布局前面的数据
- 把"东城区"放第二，避免它占据正中心
- 让"西城区"先布局，整体更平衡

#### 效果
- ✅ 整体不偏左
- ✅ 最大词不压中心
- ✅ 视觉重心稳定
- ✅ 更松散（gridSize 16）

**不是调left，而是调letter-spacing**

公式：
```
视觉居中 = 
  left: 50% + translateX(-50%) +
  letter-spacing收紧 +
  width适当加宽
```

### 2. 词云稳定的核心技巧
**调整数据顺序控制大词位置**

原理：
- ECharts按数据顺序优先布局
- 把最大词放第二而非第一
- 避免占据正中心

### 3. 地图发光的关键

- 地图不再是"平面"

不是调位置，而是调字间距：
- 8px太宽 = 视觉偏
- 4px适中 = 基本居中
- 2px紧凑 = 完美居中 ✅
